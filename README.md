# Quest Log — RPG de Produtividade

App de produtividade gamificado no estilo RPG japonês. Funciona offline e pode ser instalado no Android como um app.

## Publicar no GitHub Pages
1. Crie um repositório público (ex.: `questlog`) e envie todos os arquivos desta pasta para a raiz.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)` e salve.
3. Em 1–2 minutos o app estará em `https://SEU-USUARIO.github.io/questlog/`.

## Instalar no Android
Abra o endereço no Chrome → menu ⋮ → **Instalar app** (ou "Adicionar à tela inicial").

## Levar o progresso do Claude para o app
No app antigo: Herói → Configurações → Backup do save → Copiar.
No app novo: mesmo caminho → cole o código → Importar.
